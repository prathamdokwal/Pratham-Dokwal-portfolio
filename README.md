# Pratham Dokwal — Portfolio

Personal portfolio site built with Vite, React, TypeScript, Tailwind CSS and shadcn-ui.

## Getting started

Requires Node.js & npm.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Deploy

The output in `dist/` is a static site and can be deployed to Vercel, Netlify, Cloudflare Pages or any static host.

# ./tailwind-plus folder:

The tailwind-plus folder contains tailwind components and themes to be used as inspiration for the project.
